## Useful commands (yarn 4)
- Dev server: `yarn dev`
- Build: `yarn build` (analyze bundle: `ANALYZE=true yarn build`)
- Start production server: `yarn start`
- Lint: `yarn lint`
- Type check: `yarn typecheck`
- Prettier check/format: `yarn prettier:check` / `yarn prettier:write`
- Tests: `yarn jest` (watch: `yarn jest:watch`); full suite: `yarn test`
- Storybook: `yarn storybook` (build: `yarn storybook:build`)
